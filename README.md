Weather App 🌤️

Weather App is a simple web application that allows you to check the current weather of any city. Built with HTML, CSS, and JavaScript, it’s perfect for beginners learning web development.

Features

Search for any city and get real-time weather information

Displays temperature, weather conditions, humidity, and wind speed

Responsive and beginner-friendly design

How to Use

Clone the repository,

Open index.html in your browser

Enter a city and click the button to see the weather

Project Structure
weather-app/
├─ index.html      # Main HTML file
├─ style.css       # Styling
└─ script.js       # JavaScript for fetching weather data
